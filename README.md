# Daura Restaurant & Party Palace — Online Ordering Pro V3

Customer ordering site: `index.html`

Starter admin panel: `admin.html`

WhatsApp order number: **+977 9744444442**

## Features
- Mobile-friendly ordering UI
- Menu categories and search
- Cart and quantity controls
- Orders saved directly to the Supabase restaurant system before WhatsApp opens
- Complete WhatsApp order details with icons: items, quantity, price, total, customer name, mobile number, location, order type, payment method and notes
- Customer confirmation note: **Your order has been placed and saved in our restaurant system. Please wait for a response/reply from our restaurant. Your order will be confirmed only after we reply to you.**
- Starter admin dashboard
- Order status workflow: New → Accepted → Preparing → Ready → Delivered
